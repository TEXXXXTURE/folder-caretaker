# folder-caretaker

> 文件夹自治管理 Skill：让 Agent 生成的内容有结构、可检索、可复用。
> **核心理念：AI 与 Agent 擅长产出内容，却对自己的产出没有结构感——本 skill 给 AI 的产出建立结构。**

适用于任何文件夹形态：AI 产出物文件夹、代码库、知识库、素材库、会话导出、混合杂物堆。

## 为什么存在

绝大多数人和 AI 对话时生成的文件（报告、代码、素材、导出）**没有管理规则，用户也不会主动整理**。文件散落、命名混乱、越积越乱，最终变成无法检索的垃圾堆——这是 Agent 工作流的系统性缺陷。

本 skill 解决这个问题，双功能一体：

| 功能 | 做什么 | 什么时候用 |
|------|--------|-----------|
| **A. 持续治理** | 扫描文件夹 → 在根目录生成 `00_使用规则.md` 声明（目录地图 + 放置规则 + 禁区；项目/协作类文件夹自动带**交接与依赖方向协议**） | 说"管理这个文件夹" |
| **B. 一次性梳理** | 扫描 → 分类 → 方案确认 → 执行 → 善后 | 说"整理这个文件夹" |

## 触发方式（按需语义）

**只有用户说出「整理 / 管理文件」语义时才使用。** 不是所有文件夹都自动加规则：

- 「管理这个文件夹 / 给这个文件夹定规则」→ 功能 A
- 「整理一下这个文件夹 / 这个文件夹好乱」→ 功能 B
- 「整理完以后要一直保持」→ A + B 组合

## 协议在文件里，不在 Agent 里

整理完成后，文件夹根目录生成 `00_使用规则.md`——**协议本身**。它随文件夹存在：Agent 存取该文件夹时列目录即见（`00_` 前缀排最前），内容自述约束。不需要给 Agent 全局指令写铁律，也不需要所有文件夹都加规则。

## 整理方法论（功能 B）

1. **扫描**：完整列目录 + 文件类型统计 + 语义归类
2. **方案**：新建目录 / 移动映射表（逐一列出）/ 重命名建议 / 删除建议（只列不删）——**枚举确认，不直接动手**
3. **执行**：按确认方案移动/重命名/建目录，**不改文件内容、不删文件**
4. **善后**：清理空目录 + 生成 `00_使用规则.md` 固化为放置规则

## 整理验收标准（8 条）

| # | 标准 |
|---|------|
| 1 | 根目录不裸放：只剩规则文件 + 分类目录 |
| 2 | 每个文件有归属：无孤儿文件 |
| 3 | 目录语义自明：目录名 5 秒内看懂放什么 |
| 4 | 命名规范统一：无日期括号、无版本尾缀 |
| 5 | 无重复副本：无 `xxx(2).md` 类（有则列出交用户处置） |
| 6 | 结构不过深：分类 ≤2 层 |
| 7 | 声明在场：`00_使用规则.md` 已生成且与整理结果一致 |
| 8 | 用户确认：整理结果用户认可后才算完成 |

## 类型适配

| 类型 | 识别特征 | 声明侧重 |
|------|---------|---------|
| 代码项目 | package.json / src/ / tests/ | 结构约定、构建命令、命名规则 |
| 文档输出 | .md/.docx/.pdf 为主 | 命名规则、归档规则、frontmatter 规范 |
| 素材库 | 图/音/视频多 | 分类约定、命名模板、元数据 |
| 会话导出 | 时间戳文件名、session 字样 | 归类规则、摘要索引约定 |
| 项目/工作区夹 | 00-index / 10-projects / 环节夹 / 交接文档 | 放置规则 + **交接文档协议 + 依赖单向** |
| 混合杂物堆 | 无主导类型 | 先分类后治理、分区放置 |

## 交接与依赖方向（项目 / 协作类文件夹）

多会话、多 Agent 共用的项目文件夹（如总仓形态），声明会额外带上**记忆与交接协议**（出处：project-vault STANDARDS §16）：

- **新会话入口**：每项目一份交接文档（`04-执行状态/交接文档.md`），含一句话定位 / 现状 / 待拍板（合并全部未决项）/ 下一步 / 产品仓指针。
- **依赖单向**：文件引用只朝一个方向（内部 → 细节文件 / 外部 → 产品仓指针），禁止反向引用与循环依赖；交接文档只记指针，不镜像内容。
- **写回时机**：会话结束 / 环节推进时更新交接文档；决策 → ADR，踩坑 → debug-log，验证 → 验证记录。

## 安装

```bash
# Hermes / 任意支持 SKILL.md 的 agent
git clone https://github.com/TEXXXXTURE/folder-caretaker.git
# 将 SKILL.md 放入你的 agent skills 目录
```

## 禁区默认值（写进所有声明）

- 不删除用户手动创建的文件/结构
- 不重组已存在目录结构（除非用户明确要求）
- 不移动被其他程序占用的文件（应用目录）
- 应用文件夹（如 D:\软件）默认只生成声明，不做重组——用户不接受重组
